PB-009 correction (2026-10-21): `CLM-PB001-01` was labelled [V], C and `CLM-PB001-02` [V], A. Neither source is the IEC 61966-2-1 text, which was never obtained: SRC-PB001-01 is the ICC registry's summary and SRC-PB001-02 is a W3C CSS Candidate Recommendation Draft. [V] requires direct grounding in a cited primary specification (blueprint §1.1), so both claims are relabelled [I], inferred from secondary summaries, and graded D (blueprint: D = secondary description). ICC grade rationale: the blueprint's source hierarchy lists ICC as normative, but the registry page is ICC's summary of an IEC standard rather than an ICC specification, so it is secondary support for this claim and D, not A. The W3C definition would support [V], A only for a claim limited to CSS Color 4's own `srgb` definition. An earlier PB-009 draft (`0d8b381`) wrote “[V] … D”, which contradicts the label definition; Skeptic's re-review caught it and it is corrected here.
